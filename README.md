# Trabajo-redes

Práctica 2 de la asignatura de Redes — Grado en Ingeniería Informática (Universidad de Córdoba).

Implementación en C de una aplicación cliente/servidor sobre sockets TCP que permite jugar en red al juego **Dominio Territorial**.
